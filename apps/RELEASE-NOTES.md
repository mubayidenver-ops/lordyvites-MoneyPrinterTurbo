Lordyvites Money Printer Turbo — initial preview.

Windows 10/11, 64-bit: download and run the Windows Setup EXE. Open Lordyvites from Start, enter your OpenAI and Pexels/Pixabay API keys, and start the studio. The launcher opens the video studio in your browser. Python and FFmpeg are included; no developer tools are required.

Android 10 or newer: install the signed Android APK when attached. On the same trusted Wi-Fi as the PC, enter the PC address and pairing code shown by the Windows app. The PC must remain on with the app open. Generated videos can be saved to Downloads.

This is a personal LAN studio, not a public internet service. Do not forward its port to the internet. Internet access and your own provider credentials are needed for AI, voice and video materials; provider charges may apply. The Windows installer is not code-signed and may show an unknown-publisher prompt. This preview has not been validated with real provider credentials or physical Android hardware.

API keys, logs and generated files stay under `%LOCALAPPDATA%\Lordyvites\MoneyPrinterTurbo`. Uninstalling the app preserves this data. Restarting the PC studio disconnects paired devices and creates a new pairing code.

MoneyPrinterTurbo's original MIT license and attribution are retained. See apps/README.md in the repository for build and troubleshooting instructions.
